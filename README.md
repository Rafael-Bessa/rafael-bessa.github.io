# Rafael Morangon Bessa — Portfólio profissional

Portfólio pessoal publicado no GitHub Pages para apresentar projetos técnicos, stack, formação, cursos e conteúdo em vídeo.

## Estrutura

- `index.html` — conteúdo e estrutura semântica
- `styles.css` — design responsivo, temas claro/escuro e componentes
- `script.js` — menu mobile, tema, animações e navegação ativa
- `assets/favicon.svg` — ícone do site
- `assets/curriculo-rafael-bessa.pdf` — currículo em PDF

## Principais decisões de design

- Site diferente do currículo: sem histórico profissional detalhado.
- Projetos apresentados como mini estudos de caso, não como bullets de CV.
- Cursos agrupados por instituição/tema em acordeões para reduzir poluição visual.
- YouTube integrado como espaço de comunicação e aprendizado.
- Tema claro como padrão visual principal, com modo escuro opcional.
- HTML semântico, foco visível, skip link e suporte a `prefers-reduced-motion`.

## Publicação

O repositório `Rafael-Bessa/rafael-bessa.github.io` é publicado pelo GitHub Pages. Depois de substituir os arquivos e executar `git push origin main`, o site é atualizado automaticamente após o deploy.
